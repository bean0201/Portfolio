Background

비통신 분야에서 ‘플랫폼’이 되려는 SKT의 새로운 ‘조합’ 구독 서비스 등장

T 우주는 요금제와 멤버십 혜택 안에서 소개되며 독립적인 구독 서비스로 인식되기 어려웠습니다. 이 프로젝트는 기존 혜택과 분리된 동선에서 T 우주의 구독 가치를 이해하고 체감하는 경험을 만드는 데서 시작되었습니다.

구독 시장은 단일 구독 중심에서 여러 구독을 한 서비스에서 이용하는 구조로 변화하고 있었습니다. 반면 T 우주 구독 상품은 통신 요금제와 결합된 형태로 공급되어 사용 활성화가 저조하고 이해도가 낮은 편이었고, 요금제에 포함된 사실을 알지만 사용하지 않는 비율이 49.6%에 달했습니다.

User Research

T 우주 사용자는 상품 탐색 단계와 혜택 사용 단계에서 어려움을 겪습니다

SKT T 우주 사용자와 타사 사용자 총 6명을 대상으로 상품 탐색부터 구독과 사용까지 과업 기반 UT를 진행했습니다(2023년 1월 16일 – 2월 3일). 개별 태스크에서 평균 이상의 시간이 소요됐고, 구독 상품 사용 과제는 참여자 6명 모두 완료하지 못했습니다.

인터뷰에서는 “T 우주가 무엇인지 모르겠어요”, “상품이 광고처럼 느껴져요”, “가입 개념이 낯설고 필수 정보를 인지하기 어려워요”, “읽어야 하는 단계가 너무 많아요”처럼 복잡한 상품 구조와 가입 방식이 어렵다는 의견이 반복됐습니다.

Problem Definition 1

홈에서 상품의 종류와 구성 혜택을 구분하기 어렵습니다

기존 홈은 우주패스 상품을 중심으로 구성돼 있었습니다. 사용자는 상품마다 무엇이 포함되는지 파악하기 어려웠고, 원하는 상품으로 이동하는 경로도 명확하지 않았습니다.

사용자가 무엇을 눌러야 하는지 알기 어렵고, 어디서부터 어디까지가 하나의 상품인지 구분되지 않았으며, 상품과 관련 없는 모티브로 상품을 설명하고 있었습니다. “뭘 눌러야 할지 헷갈려요”, “우주 패스가 뭔지 모르겠어요”라는 반응이 이를 뒷받침했습니다.

Solution 1

여러 혜택을 하나의 상품으로 인식할 수 있는 카드 구조를 탐색했습니다

혜택을 강조하는 방식부터 상품 단위를 강조하는 방식까지 메인 상품 카드 구성을 비교했습니다. 그 결과, 여러 혜택이 하나의 상품으로 인지되도록 구성하는 데는 성공했지만 묶음형 상품(패스)에 포함된 항목의 관계를 더 분명히 보여줄 필요가 있었습니다.

Solution 1

상품 카드에서 기본 혜택과 추가 선택 항목을 함께 보여줍니다

패스 상품을 하나의 카드로 제시하고, 포함된 혜택을 기본 상품과 추가 상품으로 구분했습니다. 사용자는 홈에서 상품 구성을 살펴본 뒤 원하는 상품으로 이동할 수 있습니다.

하나의 구독 상품을 구성하는 여러 혜택을 순서대로 표현하고, 묶음형 구독 상품에서 사용자가 선택해야 하는 항목을 인지시키며, 담기 버튼 CTA를 통해 묶음형 구독 상품을 바로 구매하도록 유도했습니다.

Problem Definition 2

무엇을 구독하고 어떻게 이용하는지 불명확해 구독 과정에서 이탈합니다

기본 혜택과 추가 혜택을 여러 화면에서 선택해야 했습니다. 필수 정보는 선택 과정의 뒤쪽에 노출돼, 사용자가 무엇을 구독하는지 확인하기 어려웠습니다. “읽어야 하는 단계가 너무 많아요”, “가입을 하라는 게 구독을 하라는 건가요?”라는 목소리가 있었습니다.

상품에 포함된 혜택을 선택하고 조합하는 방식이 충분히 전달되지 않았고, 추가 혜택이 명확한 기준 없이 나열되어 원하는 상품을 찾기 어려웠으며, 선택 결과가 텍스트 중심으로 제공되어 어떤 상품을 골랐는지 파악하기 어려웠습니다.

Solution 2

기본 상품부터 추가 상품까지 순서대로 선택하도록 구성했습니다

상품 상세에는 기본 상품과 추가 상품을 나눠 표시했습니다. 추가 상품은 유형별로 찾을 수 있게 하고, 선택한 구성과 결제 금액을 확인한 뒤 결제로 이어지도록 했습니다.

상품 유형과 노출 기준을 명확히 보여줘 원하는 상품을 빠르게 찾도록 돕고, ‘가입하기’ 버튼은 ‘구독하기’로 레이블을 변경해 행동의 의미를 분명히 했습니다.

Problem Definition 3

구독한 혜택을 찾아 사용하기까지 여러 화면을 거쳐야 합니다

기존에는 구독 정보와 실제 사용 기능이 깊은 메뉴에 나뉘어 있었습니다. 사용자는 현재 이용 중인 상품을 확인한 뒤에도 혜택을 쓰는 방법을 다시 찾아야 했습니다. T 우주 탭 › 나의 구독 › 관리하기 › 이용상품 상세 › 바로가기를 거쳐야 우주패스 매직 바코드에 도달할 수 있었습니다.

상품 정보가 한꺼번에 노출되어 필요한 정보를 구분하기 어렵고, 상세 페이지가 이용 중인 상품 리스트와 동일한 정보를 제공하며, 필요한 상품 정보를 단계적으로 확인할 수 있는 구조가 부족했습니다. “혜택을 바로 연결할 수 있는 쉬운 방법은 없나요?”라는 요구가 반복됐습니다.

Solution 3

구독 관리의 개념을 쉽고 직관적인 사용성으로 전달합니다

구독 상품 정보를 더 명확하게 제공하기 위해 전반적인 메뉴명을 직관적인 단어로 교체하고(이용 상품 → 구독 관리, 관리하기 → 결제 관리하기, 쿠폰함 → 할인 쿠폰·이용권함), 프로그래스 바와 가입 상품·결제 정보·포함 혜택을 분산하지 않고 한 영역에 정리해 사용자가 현재 구독 상태를 빠르게 확인하고 관리할 수 있도록 했습니다.

리스트에서 상품의 상태값을 노출해 현황을 빠르게 확인하게 하고, 상세에서는 혜택 사용에 필요한 작업으로 연결하는 기능을 함께 제공했습니다.

Solution 3

상품을 선택하거나 바코드를 열어 혜택으로 바로 이동합니다

이용 화면에서 상품별 혜택을 선택하면 해당 사용 화면으로 연결됩니다. 오프라인 혜택은 바코드 버튼을 통해 바로 제시해 사용 단계의 이동을 줄였습니다.

상품을 직접 선택하면 상품별 개별 코드로 이동하며 브랜드 키 컬러로 상품 종류의 직관성을 높였고, ‘바코드 아이콘’ 버튼을 누르면 오프라인에서 빠르게 사용할 수 있는 통합 할인 바코드를 노출해 혜택 이용에 도달하는 방법을 두 가지로 제공했습니다.

Project Result

사용자 클릭 데이터로 디자인 의도에 따른 성과를 확인했습니다

패스 상품 영역의 구성 담기 버튼이 눌리지 않는 영역과 대비해 활성화되었고, 신규·재방문 여부와 상관없이 50%의 사용자가 패스 상품이 있는 중하위 영역까지 깊게 스크롤을 내려 확인했습니다.

전체 사용자 중 40.5%가 상품 상세 진입 후 ‘구독을 하기’로 결정했습니다. 구독 상품의 정보와 가격을 중요시하는 T 우주 고객들은 상품 구성을 이해하고 합리적이라고 판단해 구매를 결정합니다. 또한 ‘이용’ 페이지 안에서는 유형별은 혜택의 빠른 사용을 위해, 상품별은 상품군의 정보 확인을 위해 토글을 활발히 사용했습니다.

Project Result

클릭 데이터를 바탕으로 다음 개선 방향을 정리했습니다

좌상단의 이름 영역이 ‘회원 정보 관리’라는 기능에 비해 클릭률이 높았습니다. 사용자는 [›]를 누르면 ‘마이페이지’로 랜딩될 것이라고 예상하므로 톱니바퀴 아이콘으로 변경해 링크될 페이지의 기능을 직관적으로 인지하도록 했습니다.

담기 완료 직후 [바로가기] 버튼으로 카트에 63%가 이동했지만 결제하기 직전 10%가 이탈했습니다. 담기 바텀시트 안에 [바로 결제하기] 버튼을 추가하고 기존 카트 버튼은 [카트로 이동], [카트 보러가기]로 레이블을 정리했습니다. 본인의 이름이 노출되는 영역을 눌러보는 경향에 맞춰 이용 페이지 타이틀도 용도에 맞게 구체화했습니다.

Design System

익숙한 커머스 모듈 도입을 통해 상품 탐색 경험을 구조적으로 최적화

사용자가 편리하고 익숙하게 플랫폼을 사용할 수 있도록 일반적인 커머스 상품 모듈을 참고하고, 그룹 상품의 경우 상품에 해당하는 목록들을 쉽게 인지할 수 있도록 카드 그룹 형태로 모듈을 구성했습니다.
