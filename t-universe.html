Background

비통신 분야에서 ‘플랫폼’이 되려는 SKT의 새로운 ‘조합’ 구독 서비스 등장

T 우주는 요금제와 멤버십 혜택 안에서 소개되며 독립적인 구독 서비스로 인식되기 어려웠습니다. 이 프로젝트는 기존 혜택과 분리된 동선에서 T 우주의 구독 가치를 이해하고 체감하는 경험을 만드는 데서 시작되었습니다.

단일 구독 중심에서 여러 구독을 한 서비스에서 이용하는 구조로 변화하는 가운데, T 우주 구독 상품은 통신 요금제와 결합된 형태로 사용 활성화가 저조하고 이해도가 낮은 편이었습니다. 요금제에 포함되어 있지만 사용하지 않는 비율이 49.6%였습니다.

User Research

T 우주 사용자는 상품 탐색 단계와 혜택 사용 단계에서 어려움을 겪습니다

T 우주 사용자와 타사 사용자 총 6명을 대상으로 과업 기반 인터페이스 문제점을 파악하는 UT를 진행했습니다. 구독 상품 사용은 가장 어려운 태스크였고, 개별 태스크에서 평균 이상의 시간이 소요되었으며 참가자 6명 모두 구독 상품 사용에 실패했습니다.

인터뷰에서는 "T 우주가 무엇인지 모르겠어요", "상품이 광고처럼 느껴져요", "가입 개념이 낯설고 필수 정보를 인지하기 어려워요", "읽어야 하는 단계가 너무 많아요"처럼 상품 이해와 이용 난이도가 높다는 의견이 반복되었습니다.

Problem Definition

무엇을 구독하는지 잘 이해하지 못하고 가입 후에도 혜택을 사용하기 어려웠습니다

T 우주의 상품 이미지는 상품을 이해하는 데 큰 도움이 되지 못합니다. 또한 사용자에게 필요한 기능이 깊은 뎁스 안에 구성되어 있어 해지까지 이어지는 불편함을 줍니다.

무엇을 구독하고 어떻게 이용하는지 불명확해 탐색 과정에서 이탈하는 ‘구독 상품 정보 파악 실패’와, 상품 이용과 관리 기능이 깊은 구조에 위치해 쉽게 찾지 못하는 ‘구독 혜택 사용과 관리의 복잡성’ 두 가지 문제로 정의했습니다.

Solution Summary

T 우주만의 정체성이 담긴 서비스 속에서 직관적인 상품 탐색 및 사용 여정을 제공합니다

상품 구조를 쉽게 이해할 수 있도록 T 우주의 구독 구조를 한눈에 시각화하고, 상품의 구조를 순서대로 이해할 수 있게 하며, 상품을 고르고 담는 과정을 익숙한 커머스 흐름으로 구성했습니다.

이용과 관리의 경험이 구분되도록 혜택 사용 진입점의 접근성을 높이고, 현재 가입 상태를 중심으로 구독을 관리하도록 했습니다.

Problem · 상품 구조 이해 실패

무엇을 구독하고 어떻게 이용하는지 불명확해 탐색 과정에서 이탈합니다

AS IS 메인 홈에서는 사용자가 무엇을 눌러야 하는지 알기 어렵고, 어디서부터 어디까지가 하나의 상품인지 구분하기 어려웠습니다.

AS IS 상품 상세에서는 상품에 포함된 혜택을 선택하고 조합하는 방식이 충분히 전달되지 않고, 추가 혜택이 명확한 기준 없이 나열되어 원하는 상품을 찾기 어려웠으며, 선택 결과가 텍스트 중심으로 제공되어 어떤 상품을 골랐는지 파악하기 어려웠습니다.

Solution · 상품 구조를 쉽게 이해할 수 있도록

T 우주의 구독 구조를 한눈에 이해할 수 있도록 시각화합니다

T 우주의 상품을 쉽게 이해할 수 있도록 ‘패스 상품’을 ‘티켓’ 형태로 상품 정보와 혜택을 일관성 있게 보여줍니다. 묶음형 구독 상품(패스)을 구성하는 혜택 개수를 표현하고, 하나의 상품을 구성하는 여러 혜택을 순서대로 표현하며, 담기 버튼 CTA로 묶음형 상품을 바로 구매하도록 유도했습니다.

상품 카드 이터레이션에서 여러 혜택이 하나의 상품으로 인지되도록 구성했고, 묶음형 상품(패스)의 구성 관계가 드러나도록 보완했습니다.

Solution · 상품 구조를 쉽게 이해할 수 있도록

상품의 구조를 순서대로 이해할 수 있도록 합니다

상품에 포함된 혜택의 구조를 기본 상품, 추가 상품의 순서로 차근차근 선택하고 비교할 수 있도록 도왔습니다. 다양한 브랜드 로고를 통해 선택 가능한 상품에 대한 기대감을 형성하고, 가입하기 버튼은 구독하기로 레이블을 변경했습니다.

Solution · 상품 구조를 쉽게 이해할 수 있도록

상품을 고르고 담는 과정을 익숙한 커머스 흐름으로 구성합니다

상품 내에 포함된 상품의 개수와 혜택을 우선 확인한 후 단계적으로 원하는 혜택을 명확히 선택할 수 있도록 도왔습니다. 상품 유형과 노출 기준을 명확히 보여줘 원하는 상품을 빠르게 찾도록 하고, 선택한 상품 구성과 결제 금액을 확인한 뒤 다음 단계로 넘어가도록 했습니다.

Problem · 구독 혜택 사용과 관리의 허들

혜택 이용 기능이 깊은 구조에 위치해 쉽게 찾지 못합니다

AS IS 구독 관리에서는 상품 정보가 한꺼번에 노출되어 필요한 정보를 구분하기 어렵고, 상세 페이지에서 이용 중인 상품 리스트와 동일한 정보를 제공하며, 필요한 상품 정보를 단계적으로 확인할 수 있는 구조가 부족했습니다.

Solution · 이용과 관리의 경험이 구분되도록

구독 중인 혜택을 빠르게 찾고 바로 사용할 수 있도록 합니다

사용자가 구독 상품을 구매한 뒤 별도의 탐색 없이 바로 상세와 이용 단계로 이어질 수 있도록 진입 동선을 개선했습니다. GNB 탭에 ‘이용’을 배치해 이용 가능한 혜택에 바로 접근하고, 토글로 혜택 정렬 기준(유형별·상품별)을 전환할 수 있게 했습니다.

오프라인에서 사용하는 바코드 기능을 최상단에 노출하고, 개별 항목은 상품별 개별 바코드로 이동하며 브랜드 키 컬러로 상품 종류의 직관성을 높였습니다.

Solution · 이용과 관리의 경험이 구분되도록

구독 관리에 필요한 정보를 한곳에 모아 확인 흐름을 단순화합니다

가입 상품과 결제 정보, 포함 혜택을 분산하지 않고 한 영역에 정리해 사용자가 현재 구독 상태를 빠르게 확인하고 관리할 수 있도록 했습니다. 바로 사용 가능한 혜택을 개수 현황 버튼으로 제공하고, 리스트에서 상태값을 노출해 상품 현황을 빠르게 확인하게 했습니다.

Project Result

사용자 클릭률 데이터를 통한 디자인 의도에 따른 성과 확인

패스 상품 영역의 구성 담기 버튼이 눌리지 않는 영역과 대비해 활성화되었고, 신규·재방문 여부와 상관없이 50%의 사용자가 패스 상품이 있는 중하위 영역까지 깊게 스크롤해 확인했습니다.

전체 사용자 중 40.5%가 상품 상세 진입 후 ‘구독을 하기’로 결정했고, ‘이용’ 페이지 안에서 목적은 다르지만 상품별·유형별 토글을 활발히 사용했습니다.

Project Result

사용자 클릭률 데이터를 통한 2차 개선 방향 도출

좌상단 이름 영역의 클릭률이 ‘회원 정보 관리’ 기능에 비해 높아, 사용자가 마이페이지 랜딩을 기대한다고 보고 톱니바퀴 아이콘으로 변경했습니다.

담기 완료 직후 카트로 63% 이동하지만 결제 직전 10% 이탈해, 담기 바텀시트에 바로 결제하기 버튼을 추가하고 기존 카트 버튼 레이블을 정리했습니다. 이름 영역을 눌러보는 경향에 맞춰 이용 페이지 타이틀을 용도에 맞게 구체화했습니다.
